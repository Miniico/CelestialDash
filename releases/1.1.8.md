## CelestialDash 1.1.8

- Celestial Tears drop during thunderstorms. The dash keeps a fixed vertical lift, and the action bar shows when you can dash again or chain a second impulse. Successful dashes are quiet in chat while the action bar is active by default.
- The Celestial Amulet displays its remaining charges after purification. Each amulet retains its own capacity, including when the server configuration changes.
- Type `/cdash help` for the commands available to you. Administrators see ready-to-use examples for giving Tears and Chronicles and sending the optional resource pack.
- This release includes a versioned resource-pack ZIP with the legacy and modern item models. The default configuration points to its GitHub Releases download. Existing installations can keep their own pack or update the URL and SHA-1 together.

Replace the old plugin JAR while the server is stopped, then restart. The resource pack is optional. If you use the bundled pack, follow the [configuration instructions](https://github.com/Miniico/CelestialDash/blob/v1.1.8/README.md#enable-the-release-pack).

The gameplay and command checks used Paper 1.20 and Paper 26.3 with their matching Minecraft clients. The automated suite contains 163 tests.
